# 伴学 · AI 学习空间（MVP）

像素风 AI 伴学网页的**可运行原型**。

---

## 一、怎么打开

### 方式一（推荐）：双击 `start.bat`

- **直接双击就行**，会自动弹出一个黑色命令窗口并打开浏览器
- ⚠️ **不要用「打开方式 → 记事本」**——那样只会看到一堆代码文字
- ⚠️ 如果窗口**一闪就没了**，说明这台电脑**没装 Node.js**，看下面的方式二
- 黑窗口**不要关**，关了服务就停了

### 方式二（无需任何环境）：双击 `index.html`

- 同样**直接双击**，会在浏览器里打开
- 功能基本一样，只是部分浏览器对本地文件的网络请求限制更严
- 如果调 API 报跨域错误，就改用方式一

> **为什么方式一更稳**：`file://` 协议下浏览器对跨域请求限制更严，走 `http://localhost` 更稳。
> 本机已装 Node.js v24；默认端口 **8765**，被占用会自动顺延（8080 常被 Steam 等程序占用，已避开）。

### 队友电脑上跑不起来？

`start.bat` 会自动检测：如果没装 Node.js，它会**打印一段说明并停住**（不会一闪而过），告诉你去 [nodejs.org](https://nodejs.org) 下载 LTS 版。

**想让队友零配置体验，最省事的办法是：直接双击 `index.html`。**

## 二、配置 AI（对话功能需要）

1. 点**右上角 ⚙**
2. 填三项：
   - **API 地址**：填官方文档里的 **BASE URL** 即可（如 `https://api.deepseek.com`），路径会自动补全
   - **API Key**：去 platform.deepseek.com 申请
   - **模型名称**：默认 `deepseek-chat`
3. 保存 → 就能对话了

> **Key 只存在你自己的浏览器里**（localStorage），不会上传到任何服务器。
> 填完整端点 `https://api.deepseek.com/v1/chat/completions` 也支持。

## 三、核心功能：疑问库（这一版的重点）

这是产品的**灵魂机制**，不是普通聊天：

```
你在学习中冒出一个疑问
        ↓
点右侧「临时对话」问它，比如「什么是免疫防御」
        ↓
AI 回答，同时在后台自动判断：
「这是不是一个学科知识疑问？」
        ↓ 是
自动打标签入库（学科 + 知识点）→ 你的「疑问库」
        ↓
隔一段时间，AI 反过来考你
        ↓
答对 → 拉长复习间隔；答错 → 重新排队
```

### 怎么用

| 步骤 | 操作 |
|---|---|
| 1. 提问 | 右侧「临时对话」→ 输入问题（如"什么是免疫防御"） |
| 2. 自动入库 | 问完会提示「已记进疑问库 · 生物 · 免疫防御的三道防线」 |
| 3. 看库 | 点**右上角 📚**，看到所有疑问 + 掌握度进度条 |
| 4. 复习 | 点「开始复习」，用自己的话复述 → AI 判定对错 → 自动安排下次复习时间 |

**间隔重复算法**：答对依次按 1 / 3 / 7 / 15 / 30 天拉长间隔，答错重置回 1 天。

## 五、书架：任务即书籍

左上角那面**背景里的书柜**现在就是你的书架 —— 不再是浮在画面上的卡片：

- **木质铭牌**：钉在书柜上方的墙面上，写着「书架」和 `已读/总数 本`
- **书脊**：直接**站在背景书柜第 2 层那块层板上**，不遮住背景（层板在画里是右端向下斜的，
  整行书跟着转 0.35°，看起来就是站在那块木板上）
- **🗄 抽屉**：读书笔记（阅读位）和「加书」输入框收在里面，默认收着 ——
  平时画面就是一间干净的房间；点书名方那颗钉子拉开，开始读书时会自动拉开

| 动作 | 对应的事 |
|---|---|
| 拉开 🗄，在底部写下一个任务 | **上架一本新书**：书脊带着上架动画落进书柜的空位 |
| 点书脊 | **开始读这本书**＝这项任务正在进行：书从架上被抽下来、飞到抽屉的阅读位落定，同时开始计时 |
| 读的时候在「临时对话」提问 | AI 回答完顺手**提炼一条要点**写进这本正在读的书；这段时长也记在这本书上 |
| 点「合上放回」 | **把书放回书柜**：反向播放归架动画，书插回它原来在书柜上的那个位置 |
| 点「读完了」 | 同上，但书进入「读完」状态，横躺到书柜上方那一摞，书脊上留一道绿线 |

- **书脊宽度**＝书名长度 + 要点条数 + 已读时长；**颜色**取自背景书柜的调色板（暗红 / 藏蓝 / 墨绿 / 土黄），
  再加一圈深色描边 —— 背景里本来就画满了书，我们的书只有描边够硬才认得出来
- **在读标记**：正在读的那本，书脊下方有一道金线
- 点书柜上方那一摞、或点铭牌上的 ▤，可以看**读过的书**清单
- 按住 `Shift` 点书脊 = 直接翻这本书的要点，不改变在读状态
- 书页弹窗里能看到每一条要点（什么时候写的、来自哪个提问），也能「退掉这本书」（＝删掉这条任务）

### 时长怎么算

- 只在「这本书正在读」的时候累计；**一次只读一本**（点另一本会自动把当前那本合上放回）
- 每 5 秒刷新显示，每 15 秒落一次盘；关掉页面前也会补算
- 切到别的标签页**不暂停**（待办常和白噪音、番茄钟一起用），关掉浏览器会按时间戳补算

### 归架动画（三拍）

参考视频里提取的动作语法，正向是「抽下来」、反向是「放回去」：

1. **Z 轴流动**：书沿弧线离开书架，旋转中带一点侧倾，近大远小 —— 不是平面平移
2. **落位转身**：接近目标时绕 Y 轴转正、带一点 overshoot 再回落
3. **错峰展开**：落定后阅读位的内容一行一行依次浮现（每层延迟 70ms）

落架瞬间还会溅几个微尘粒子。整个飞行只有一个克隆体在动，原书脊立刻隐身 —— 不会出现两本书。

> 数据在 `localStorage.study_books`，和 `study_todos` 一一对应；
> **老的待办会自动迁移成书，一条都不会丢**（`done` 的转成「读完」状态）。

## 六、演示模式（录视频专用）

网址后面加参数，打开即是对应状态：

| 参数 | 效果 |
|---|---|
| `?demo=radial` | 直接展开辐射菜单 |
| `?demo=sidebar` | 直接打开对话侧栏 |
| `?demo=setting` | 直接打开接口设置 |
| `?demo=pomo` | 直接拉起番茄钟 |
| `?demo=vault` | 直接打开疑问库 |
| `?demo=review` | 直接进入复习卡片 |
| `?demo=noise` | 直接打开白噪音面板 |
| `?demo=reading` | 自动挑一本开始读（演示归架动画、写要点用） |
| `?demo=book` | 直接打开第一本书的书页 |
| `?demo=stack` | 直接打开「读过的书」 |
| **`?mock=1`** | **注入 3 条示例疑问**（只在库为空时生效） |
| **`?ai=mock`** | **AI 走本地假接口**：不填 Key、不联网也能把「提问 → 提炼 → 写进书里」整条链路跑通 |

**推荐组合**：`?mock=1&demo=vault` 或 `?ai=mock&demo=reading`

> `?ai=mock` 是给开发自测和离线演示用的：假的回答会走和真接口完全一样的格式
> （正文 + 一行 `<tag>{...}</tag>`），所以切到真接口时下游代码一行都不用改。

## 七、白噪音（不用任何音频文件）

右上角 🎧 打开面板，五种声音**全部由浏览器现场合成**（Web Audio），仓库里一个 mp3 都没有：

| 声音 | 怎么合成的 |
|---|---|
| 🌧️ 雨声 | 白噪声 + 高通/低通滤波，衰减高频，只做极慢的强弱变化 |
| 🌊 海浪 | 布朗噪声 + 低通，滤波频率和音量都挂在 8 秒周期的 LFO 上（潮起潮落） |
| ☕ 咖啡馆 | 粉噪声分两路：宽频当房间底噪、带通当人声「嗡嗡」，再叠随机杯碟轻响 |
| 🔥 壁炉 | 布朗噪声低频轰鸣 + 随机噼啪（带通白噪 + 极快包络） |
| 🎚️ 静噪 | 干净的布朗噪声，最不抢注意力 |

- **音量** 0–100，平方曲线，低音量段更好调；存在浏览器里，下次打开还是这个音量
- **番茄钟联动**：勾上「番茄钟开始时自动播放，结束时自动停」，之后点番茄钟就会连白噪音一起开关。
  **手动开的**白噪音不会被番茄钟顺手停掉 —— 只有它自己带起来的才由它负责关
- 面板里点同一个声音两次 = 停止
- 声音只在你自己这台机器上响，不联网、不占存储

> **第一次要在页面上点一下才会出声** —— 浏览器规定音频必须由用户操作唤醒，这是浏览器的规矩，不是 bug。
> 同一个道理：页面刚打开就点番茄钟是不会响的，得先随便点一下页面。

## 八、数据存在哪 / 怎么搬走

| 数据 | 位置 |
|---|---|
| 疑问库、待办、**书架（每本书的要点与时长）**、对话历史 | 浏览器 localStorage |
| API 配置 | 浏览器 localStorage |
| 白噪音偏好（音量、默认声音、是否联动） | 浏览器 localStorage |

**换电脑、清缓存会丢** —— 所以疑问库右上角有 💾 **数据备份**：
导出成一个 JSON（**不含 API Key**，但**包含书架**：每本书的要点与阅读时长都在里面），
在新机器上导入即可。导入会覆盖当前疑问库与书架，先导一份更稳。

> 每本书的要点只存**提炼后的短句**，不存问答全文，所以一本书攒几十条也占不了多少空间。

## 十、技术说明

| 项 | 说明 |
|---|---|
| 形式 | 单文件 HTML（内联 CSS + JS），零依赖 |
| 图像 | `frames/` 里 6 张 2080×1022 的 jpg 姿态图 + 底图 `bg.jpg`（仓库原样） |
| 人物动画 | 6 个常驻 `<img>` 图层，只切 `opacity`；每 3~10 秒随机换姿态；切到微笑帧时随机眨一次眼 |
| 书脊 | 每本书一个内联 SVG（木纹渐变 + 书脊线 + 竖排书名 + 状态线），缩放不失真 |
| 归架动画 | Web Animations API + CSS 3D：一个克隆体沿关键帧飞行（translate + rotateY + scale），落位后交给阅读位里那本常驻的书 |
| 接口 | OpenAI 兼容；地址支持 BASE_URL 自动补全；`?ai=mock` 可切本地假接口 |
| 上下文 | 每次带最近 16 条消息 |
| 打标签 | 让 AI 在回答末尾输出 `<tag>{...}</tag>`，前端抽取后从正文剔除 |
| 书的要点 | 读某本书时给系统提示追加一条指令：在 `<tag>` 里多给一个 `note` 字段（≤120 字，用「；」分隔短句）；提炼失败就退回自动截取并标注「未提炼」 |
| 判定 | 复习时让 AI 输出 `<result>{...}</result>`，解析 level / comment / missing |
| 白噪音 | Web Audio：白/粉/布朗噪声 buffer（4 秒无缝循环）+ 滤波器 + LFO；不加载音频文件 |
| 本地服务器 | 带 ETag/304，刷新页面不再重传没变的图 |
