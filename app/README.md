# 伴学 · AI 学习空间（MVP）

像素风 AI 伴学网页的**可运行原型**。

---

## 一、怎么打开

**双击 `index.html`**，或在浏览器里打开它（推荐 Chrome / Edge）。

不需要装任何东西，不需要启动服务器。

---

## 二、配置 AI（对话功能需要）

1. 点画面**右边缘的「临时对话」把手**，打开侧栏
2. 点侧栏右上角的 **⚙**
3. 填三项：
   - **API 地址**：**填官方文档给的 BASE URL 就行**（如 `https://api.deepseek.com`）—— 页面会**自动补上** `/chat/completions`；也可以直接填完整端点
   - **API Key**（去 platform.deepseek.com 申请，或换成通义/Kimi/OpenAI 的 Key）
   - **模型名称**（默认 `deepseek-chat`）
4. 点**保存**，然后就能对话了

> **Key 只存在你自己的浏览器里**（localStorage），不会上传到任何服务器。

---

## 三、有什么功能

| 功能 | 怎么用 |
|---|---|
| **To-Do List** | 左上角。输入框打字回车添加；点方块勾选；鼠标移到条目上出现 ✕ 删除 |
| **辐射菜单** | **点画面中间的人物**，六个按钮会散开 |
| **临时对话** | 点右侧「临时对话」把手；或辐射菜单里的「问问题」 |
| **番茄钟** | **点右上角 🍅 按钮**；或辐射菜单 → 番茄钟（25 分钟倒计时） |
| **接口设置** | **点右上角 ⚙ 按钮**；或辐射菜单 → 设置，或侧栏右上角 ⚙ |

**辐射菜单六个按钮**：番茄钟 · 问问题 · 考考我 · 错题本 · 设置 · 关闭

## 四、演示模式（录视频时很有用）

在网址后面加参数，打开就是对应状态，不用手动点：

| 参数 | 效果 |
|---|---|
| `index.html?demo=radial` | 直接展开辐射菜单 |
| `index.html?demo=sidebar` | 直接打开对话侧栏 |
| `index.html?demo=setting` | 直接打开接口设置 |
| `index.html?demo=pomo` | 直接拉起番茄钟 |

> 录演示视频时，用这些参数可以省下点击动作，剪辑更好看。
