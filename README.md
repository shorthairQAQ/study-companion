# 伴学 · AI 学习空间

> **一个 AI 陪着你学习的空间 —— 你在这里问过的每一个问题，它都记得，并且会回来考你。**

像素风网页应用。学生随时抛出零碎疑问（「什么是免疫防御？」），AI 回答的同时自动判断这是不是一个学科知识疑问，打上标签存进「疑问库」；之后按遗忘曲线（1/3/7/15/30 天）**反过来考他**，答对拉长间隔、答错重新排队。

---

## 想看效果？30 秒

**直接双击 `app/index.html`** —— 不需要安装任何东西。

想用完整功能（AI 对话），点右上角 **⚙** 填入自己的 API Key 即可（见下方「配置 API」）。

> 如果你装了 Node.js，更推荐双击 `app/start.bat`：它会起一个本地服务器（`http://localhost:8765`）再打开浏览器，避开 `file://` 协议的网络限制。**没装 Node 也没关系**，`start.bat` 会检测并提示你，此时用 `index.html` 即可。

## 配置 API

对话与判分需要一个大模型接口（**OpenAI 兼容格式**）：

1. 点右上角 **⚙**
2. 填三项：
   - **API 地址**：填官方文档给的 BASE URL（如 `https://api.deepseek.com`），路径会自动补全
   - **API Key**：去 [platform.deepseek.com](https://platform.deepseek.com) 自行申请
   - **模型名称**：默认 `deepseek-chat`
3. 保存

> **API Key 只存在你自己的浏览器里**（localStorage），不会上传到任何服务器，也不会进这个仓库。
> **每个人要用自己的 Key。**别人共享 Key 等于共用额度，不要这么做。

## 怎么用

| 功能 | 怎么操作 |
|---|---|
| **提问**（核心入口） | 点右侧「临时对话」把手，随手问问题 |
| **疑问自动入库** | 问完会提示「已记进疑问库 · 生物 · 免疫防御的三道防线」 |
| **看疑问库** | 点右上角 📚（带待复习数量的角标） |
| **复习 / 考我** | 疑问库 → 「开始复习」，用自己的话复述 → AI 判定 |
| **辐射菜单** | 点画面中间的人物 |
| **番茄钟** | 右上角 🍅 |
| **待办** | 左上角，回车添加 |

### 演示参数（录视频/截图时很有用）

在网址后加参数，打开即是对应状态：

| 参数 | 效果 |
|---|---|
| `?demo=radial` | 展开辐射菜单 |
| `?demo=sidebar` | 打开对话侧栏 |
| `?demo=vault` | 打开疑问库 |
| `?demo=review` | 进入复习卡片 |
| `?demo=setting` | 打开接口设置 |
| `?demo=pomo` | 拉起番茄钟 |
| **`?mock=1`** | **注入 3 条示例疑问**（仅在库为空时生效） |

**推荐组合**：`index.html?mock=1&demo=vault`

## 技术栈

| 层 | 用什么 |
|---|---|
| 前端 | **原生 HTML + CSS + JavaScript**，单文件，零依赖、零构建 |
| 数据 | 浏览器 `localStorage`（疑问库 / 待办 / 对话历史 / API 配置） |
| 接口 | OpenAI 兼容的 REST API（前端直连） |
| 本地服务器 | Node.js 原生 `http` 模块（零 npm 依赖，仅开发用） |

**为什么不用框架**：这是三个零基础的同学在一个月内做的比赛作品，第一优先级是「能跑起来、能交付」，而不是技术先进。单文件让 AI 协作与调试都更简单。

## ⚠️ 给协作者的提醒

1. **文档里的路径是作者本机的**
   你会看到 `C:\Users\14351\test\...` 这类路径，**请替换成你自己 clone 下来的路径**。

2. **第一次打开疑问库是空的** —— 这是正常的（数据存在你自己的浏览器里）。想快速看到有数据的样子，加 `?mock=1`。

3. **建议用 Chrome 或 Edge**。

4. **提交前请确认没有把自己的 API Key 写进代码** —— 正确做法是只存在页面的设置面板里。

5. **提交信息用中文**，格式 `type(scope): 描述`，type 取 `feat` / `fix` / `docs` / `chore`。
